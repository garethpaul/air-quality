# Upgrade Ruff to 0.15.16

## Context

The repository pins its formatter and linter so local and hosted checks use the
same behavior. The development tool pin was one patch behind the maintained
stack: `requirements-dev.txt` used Ruff 0.15.15 while 0.15.16 was already
available and covered by PR #26.

## Scope

- Update `requirements-dev.txt` from Ruff 0.15.15 to Ruff 0.15.16.
- Update `scripts/check-baseline.sh` so the exact pin and this completed plan
  remain part of the repository contract.
- Record the toolchain change in maintained user-facing project notes.
- Leave runtime dependencies, application behavior, workflow structure, and
  security boundaries unchanged.

## Verification

- `python -m ruff --version` reported Ruff 0.15.16.
- `make check` passed on Python 3.12.8 and Python 3.14.5, including Ruff
  formatting, Ruff lint, all 108 tests, Python bytecode compilation, and the
  portable baseline checker.
- `python -m pip_audit -r requirements.txt -r requirements-dev.txt` reported no
  known vulnerabilities for the pinned direct requirements.
- Before the baseline contract was updated, changing only `requirements-dev.txt`
  to Ruff 0.15.16 failed with `requirements-dev.txt must keep the exact Ruff
  pin.`

## Risk

A formatter or lint patch can expose new diagnostics. The full local matrix
keeps that risk bounded; any future diagnostic should be fixed in source rather
than suppressed or excluded.
