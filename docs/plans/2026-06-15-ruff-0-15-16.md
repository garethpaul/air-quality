# Upgrade Ruff to 0.15.16

## Context

The runtime dependencies remain current on PyPI, but the exact development
tool pin is one patch behind: `requirements-dev.txt` uses Ruff 0.15.15 while
0.15.16 is available. The repository intentionally pins its formatter and
linter so local and hosted checks use the same behavior.

## Priorities

1. **P0 - Reproducible toolchain:** update the exact Ruff pin and the baseline
   contract that prevents local and hosted lint behavior from drifting.
2. **P1 - Compatibility:** run formatting, lint, tests, compilation, and the
   complete baseline under Ruff 0.15.16 without weakening any existing rule.
3. **P2 - Maintained evidence:** record the upgrade and preserve a completed
   plan with the exact verification and mutation results.

## Scope

- Update `requirements-dev.txt` from Ruff 0.15.15 to 0.15.16.
- Update `scripts/check-baseline.sh` to require the new exact pin and this plan.
- Record the tooling change in `CHANGES.md` and the maintained development
  command guidance in `README.md`.
- Keep runtime dependencies, application behavior, workflow structure, and
  security boundaries unchanged.

## Verification

- Confirm the installed Ruff binary reports 0.15.16.
- Run `make lint`, `make test`, `make build`, and `make check`.
- Run the complete check from an external working directory through the
  absolute Makefile path.
- Mutate the Ruff pin and completed-plan evidence in isolated copies and prove
  the baseline checker rejects both changes.
- Audit the exact diff, generated artifacts, and credential-shaped additions.

## Risks

- A formatter or lint patch may expose new diagnostics. Any diagnostic will be
  fixed in source rather than suppressed or excluded.
- Hosted installation depends on PyPI availability, while the repository pin
  continues to provide deterministic version selection.

## Work Completed

- Updated the exact development dependency and baseline contract to Ruff
  0.15.16 without changing runtime dependencies or workflow behavior.
- Kept the maintained README and changelog aligned with the reproducible lint
  toolchain.

- Isolated hostile mutations of the exact pin, maintained documentation, and
