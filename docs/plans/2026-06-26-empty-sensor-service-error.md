# Empty Sensor Dataset Service Error Implementation Plan

Status: Completed

> **For Claude:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task.

**Goal:** Return the existing service-error boundary when a valid request receives no usable upstream sensor reading.

**Architecture:** Keep caller validation and route handlers unchanged. Reclassify only the data-layer exhausted-results branch from `ValueError` to the existing stable `RuntimeError`, with independent tests for empty and all-invalid datasets.

**Tech Stack:** Python 3.12/3.14, `unittest`, Bottle-compatible route helpers, Ruff, GNU Make.
